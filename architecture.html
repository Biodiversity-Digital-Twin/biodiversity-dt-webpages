System Architecture

Technical design of the Earth System Digital Twin

Architecture Overview

The schematic architecture of the proposed ESDT integrates external data sources, internal processing subsystems, and visualization capabilities to deliver actionable insights for science and application users. The system is designed around seven interconnected subsystems that work together seamlessly.

System Architecture Diagram

Architecture Components

External Data Sources

The system integrates data from a diverse set of external sources including:

  • Field Networks: ForestPlots.net, ForestGEO, AfriTron, Liege University, CongoFlux
  • Remote Sensing: GEDI (spaceborne LiDAR), Airborne LiDAR, Airborne SAR (AfriSAR), Drone LiDAR
  • Satellite Imagery: Landsat, VHR, ALOS-PALSAR
  • Land Cover Products: GFC, TMF, RADD, GLAD
  • Animal Tracking: Movebank

Internal Subsystems

Seven specialized subsystems process and analyze data:

Ingest Subsystem - Acquires and ingests external data
Record Subsystem - Stores and manages data efficiently
Model Subsystem - Runs process-based and surrogate models
What-Then & What-Now Subsystem - Analyzes current state
What-Next Subsystem - Generates future forecasts
Visualization Subsystem - Creates interactive visualizations
Front-End Subsystem - Provides web portal access

Data Flow

The architecture supports efficient data flow through:

  • Internally Generated Data: Processed outputs from analytical subsystems
  • Model Call Pipelines: Automated workflows for model execution
  • API Routing: RESTful APIs connecting subsystems and users

Cloud Infrastructure

The system leverages Azure cloud services for scalability and performance:

  • Azure Blob Storage: Data storage in Planetary Computer
  • Azure Functions: Serverless compute for data ingestion and on-demand models
  • Azure Batch: High-performance computing for batch model runs
  • Azure Databricks: Big data processing and analytics
  • Azure Machine Learning: ML model training and deployment
  • Azure Apps: Web application hosting
