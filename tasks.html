Research Tasks

Six interconnected tasks spanning past, present, and future

What Then and What Now (Past/Current State and Drivers)
Task 1

Forest Structure Characterization

Characterize the current state of forest structure, intactness, and carbon storage using spaceborne and airborne remote sensing, combined with in situ field measurements.

Key Activities:

  • Integration of GEDI, Landsat, and Sentinel satellite data
  • Airborne LiDAR and SAR data processing
  • Field inventory data collection and validation
  • Wall-to-wall forest structure mapping
Task 2

Regional Drivers Analysis

Quantify regional drivers of change in forest extent and fragmentation using long-term Earth observation records and socio-economic datasets.

Key Activities:

  • Long-term land cover change analysis (2000-present)
  • Population and infrastructure data integration
  • Protected areas and policy impact assessment
  • Driver-response model development
Task 3

Habitat Suitability Modeling

Model habitat suitability and biodiversity corridors using outputs from Task 1 and animal movement data derived from satellite tracking.

Key Activities:

  • Animal movement data analysis (Movebank)
  • Habitat suitability model development
  • Connectivity corridor identification
  • Species-specific conservation assessments
What Next (Forecasting and Scenarios)
Task 4

Forest Change Forecasting

Forecast changes in forest extent, fragmentation, and carbon storage by integrating outputs from Tasks 1 and 2.

Key Activities:

  • Land use change model development
  • Near-term forecasts (present-2050)
  • Scenario-based projections
  • Uncertainty quantification
Task 5

Climate Scenario Projections

Project future forest structure, intactness, and carbon storage under climate scenarios using the Ecosystem Demography Model (ED2.2) and its emulator, parameterized with outputs from Tasks 2 and 3.

Key Activities:

  • ED2.2 model calibration and validation
  • Climate forcing data integration
  • Long-term vegetation projections (2017-2100)
  • Surrogate model development for rapid exploration
Task 6

Future Corridor Forecasting

Forecast habitat suitability and biodiversity corridors by combining models from Task 3 with projected ecosystem states from Task 5.

Key Activities:

  • Future habitat suitability projections
  • Corridor connectivity under climate change
  • Conservation priority identification
  • Adaptive management scenario testing
